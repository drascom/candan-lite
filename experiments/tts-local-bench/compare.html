Türkçe TTS karşılaştırma

Satır = cümle, sütun = model. Sütunlar iki gruba ayrık: DEFAULT = modelin kendi doğal sesi, KLON = ayhan referansıyla klonlanmış, OMNIPICK = beğenilen sesten çıkarılan yeni referans, NORM = metin normalizasyonu karşılaştırması (trnorm vs OmniVoice dahili). Ana karşılaştırma ekseni default seslerdir; klonlama bonus. Alttaki duygu satırları ayrı test seti (etiketli cümleler).
